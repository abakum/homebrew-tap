# Abakum Tap

## How do I install on macOS?

- `brew install --cask abakum/tap/crocson` then
- `brew upgrade --cask crocson`

Or
- `brew tap abakum/tap` then
- `brew install --cask crocson` then
- `brew upgrade --cask crocson`

## How do I install on Linux?

- `brew install abakum/tap/crocson` then
- `brew upgrade crocson`

Or
- `brew tap abakum/tap` then
- `brew install crocson` then
- `brew upgrade crocson`

## How do I install on Windows?
- `scoop bucket add abakum https://github.com/abakum/homebrew-tap`
- `scoop bucket list`
- `scoop install crocson`
- `scoop update crocson`

## How do I run on macOS?

`open /Applications/crocson.app`

## How do I run on Linux?

- `crocson`
- `gtk-launch com.github.abakum.crocson`

## How do I run on Windows?

`crocson`
